# 07. React 자유게시판 — 프론트엔드 CRUD 실습

[← 포트폴리오](../README.md) · [원본 저장소 안내](../REPOSITORIES.md)

**형태:** 개인 학습 프로젝트  
**기술:** React · React Router · Vite  
**원본:** [sukwon2000k/react-Exam](https://github.com/sukwon2000k/react-Exam)

라우터를 이용한 목록·작성·상세·수정 화면과, React 상태로 게시글 및 댓글 데이터 변경을 구현한 프로젝트입니다. **DB 및 localStorage가 없고 더미데이터를 사용하므로 새로고침 시 초기화됩니다.**

핵심 코드: [App.jsx](https://github.com/sukwon2000k/react-Exam/blob/main/src/App.jsx) · [더미데이터](https://github.com/sukwon2000k/react-Exam/blob/main/src/data/dummyData.js)

> 백엔드 API/DB CRUD 구현으로 소개하지 않습니다.
